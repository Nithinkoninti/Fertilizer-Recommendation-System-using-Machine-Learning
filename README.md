# Fertilizer Recommendation System

## Overview
This project uses Machine Learning to recommend the most suitable fertilizer based on soil properties, crop type, and environmental conditions.

## Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Fertilizer prediction
- Performance evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Tkinter

## Dataset Features
- Soil Type
- Soil pH
- Soil Moisture
- Nitrogen
- Phosphorus
- Potassium
- Temperature
- Humidity
- Rainfall
- Crop Type

## Machine Learning Algorithms
- LDA
- SVM
- QDA
- Stacking Classifier

## How to Run
1. Clone the repository.
2. Install the required libraries.
3. Run `main.py`.
